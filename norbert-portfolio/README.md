# Norbert Ábel Rédei — Portfolio

A personalized, responsive React portfolio inspired by the section-led presentation of [developerFolio](https://github.com/saadpasta/developerFolio), populated from Norbert's CV.

## Run locally

Requires Node.js and npm.

```bash
cd norbert-portfolio
npm install
npm run dev
```

Open the URL shown by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Contents

- `index.html` — page metadata and app entry point
- `src/main.jsx` — portfolio sections, content, interaction and links
- `src/styles.css` — responsive visual design
- `public/Norbert-Redei-CV.pdf` — CV PDF used by the download links

The portfolio includes profile, expertise, career timeline, certifications, education, leadership, recommendation excerpts and contact sections. Its text is based on the supplied CV. Personal projects were not invented where none were listed in the CV.
